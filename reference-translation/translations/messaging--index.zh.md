# 訊息傳遞

Spring Framework 提供廣泛的訊息系統整合能力，從使用 [`JmsClient`][r1] 簡化 JMS API 操作，到完整的非同步訊息接收基礎設施。Spring AMQP 為 Advanced Message Queuing Protocol 提供類似功能。Spring Boot 也提供 [`RabbitTemplate`][r2] 與 RabbitMQ 的自動設定選項。

Spring WebSocket 原生支援 STOMP 訊息傳遞，Spring Boot 則透過 starter 與少量自動設定加以支援。此外，Spring Boot 也支援 Apache Kafka 與 Apache Pulsar。
