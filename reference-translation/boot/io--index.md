大多數應用程式在某個階段都需要處理輸入與輸出。
Spring Boot 提供工具及多種技術的整合，協助你實作 IO 功能。
本節涵蓋快取、驗證等標準 IO 功能，以及批次處理、排程、分散式交易等進階主題。
我們也會說明如何呼叫遠端 REST 或 SOAP 服務，以及傳送電子郵件。
