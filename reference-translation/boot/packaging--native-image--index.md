[GraalVM 原生映像][packaging--native-image--index-r1]是將已編譯的 Java 應用程式進行預先處理後，產生的獨立可執行檔。相較於在 JVM 上執行的對應應用程式，原生映像通常使用較少記憶體，也能更快啟動。

[packaging--native-image--index-r1]: https://www.graalvm.org/native-image/
