Spring Boot 包含多項額外功能，協助你在應用程式部署到正式環境後進行監控與管理。
你可以選擇透過 HTTP 端點或 JMX 管理及監控應用程式。
稽核、健康狀態與指標收集也能自動套用到應用程式。
